# Go Unmanual · Gauge Room

Calibration management for Indian manufacturing plants, by **Go Unmanual**. Branding lives in `src/brand.ts`; the public landing page is `/`.

**Deploying to a server:** see [DEPLOY.md](DEPLOY.md) (Docker Compose or plain Node + PostgreSQL).

Audit-ready calibration on autopilot for Indian manufacturers — from due date to verified certificate, with your labs plugged in.

See `CLAUDE.md` for architecture and conventions, and `docs/DECISIONS.md` for assumptions.

## Prerequisites

- Node.js 22+ and pnpm (`corepack enable pnpm`)
- **Either** Docker (recommended) **or** nothing extra: `pnpm db:start` runs an embedded Postgres

## Setup

```bash
pnpm install
cp .env.example .env          # leave SMTP_HOST empty to print emails/magic links to the console
```

Start the services, using **one** of these:

```bash
docker compose up -d          # Postgres 16 :5432, MinIO :9000 (console :9001), Mailpit :8025
pnpm db:start                 # no Docker: embedded Postgres on :5432 (keep it running in its own terminal)
```

Then:

```bash
pnpm db:deploy                # apply migrations
pnpm db:seed                  # demo org, 2 plants, a user per role
pnpm dev                      # http://localhost:3000
pnpm worker                   # background jobs (notifications, 09:00 IST digest) — separate terminal
```

## Quality checks

```bash
pnpm run ci                   # lint + typecheck + unit + integration tests (needs Postgres)
pnpm test:e2e                 # Playwright (first time: pnpm exec playwright install chromium)
```

Integration tests use `gauge_room_test`. E2E resets and seeds `gauge_room_e2e` and runs its own server on :3100.
Both databases are created by `docker/postgres-init.sql` or `pnpm db:start`.

## Try the import

A messy 2,000-row register is generated by `pnpm tsx scripts/fixtures/messy-register.ts 2000 my-register.xlsx` (title row, odd headers, mixed date formats, a few broken rows). Upload it at **Instruments → Import from Excel**.

## Useful commands

| Command           | What it does                                              |
| ----------------- | --------------------------------------------------------- |
| `pnpm db:migrate` | Create/apply a migration in dev (then `pnpm db:generate`) |
| `pnpm db:reset`   | Drop, migrate and seed the dev database                   |
| `pnpm format`     | Prettier                                                  |
