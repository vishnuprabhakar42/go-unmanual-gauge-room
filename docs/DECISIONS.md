## M6 — Certificate verification & OOT (2026-10-23)

| #   | Decision                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | Why / how to reverse                                                |
| --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| 67  | **Pass/fail by simple acceptance** (ILAC-G8): a point passes when \|as-left − nominal\| ≤ permissible error. Uncertainty isn't subtracted (no guard band); points where \|error\| + U exceeds the limit are flagged "marginal" but still pass.                                                                                                                                                                                                                                                                                                                                           | Guard-banded decision rules can be added per instrument type later. |
| 68  | **As-found failures count.** If any as-found reading is outside tolerance but the instrument passes after adjustment, the result is PASS (instrument back in store) **and** an assessment-only OOT case (`AS_FOUND_FAIL`) opens, because products measured before calibration may be affected. Scrap/repair dispositions don't apply to these cases.                                                                                                                                                                                                                                     | IATF 16949 7.1.5.2.1 asks for the validity of earlier results.      |
| 69  | **Checklist: document defects reject, results decide.** Missing or wrong certificate data (number, ULR for NABL work, date in the future or before dispatch, NABL mark, accreditation number ≠ the lab's NABL number on file, outside the lab's scope, no uncertainty) blocks the decision; the verifier rejects the certificate back to the lab (job → RETURNED, file unlinked but kept, lab emailed). Only out-of-tolerance readings produce FAIL.                                                                                                                                     | —                                                                   |
| 70  | **Scope check is automatic when the lab has scope rows**; otherwise the verifier confirms it from the lab's NABL scope (one extra yes/no).                                                                                                                                                                                                                                                                                                                                                                                                                                               | Labs without scope data shouldn't block verification.               |
| 71  | **Default permissible error** comes from the instrument's +tolerance, else parsed from the tolerance text ("±0.02 mm" → 0.02, "±1% FS" → 1% of the range span). Reading-relative tolerances, grades and IT classes are entered per point.                                                                                                                                                                                                                                                                                                                                                | —                                                                   |
| 72  | **PASS**: last calibrated = certificate date, next due recomputed from the frequency, instrument → IN_STORE, job → VERIFIED_PASS → CLOSED, prompt to print a new label. A PO closes when all its jobs are verified; the request closes when all its POs are closed. **FAIL**: instrument → ON_HOLD_OOT, job → VERIFIED_FAIL (closes when the OOT is decided), OOT case with the previous calibration date as "last good", quality heads notified (email/WhatsApp).                                                                                                                       | —                                                                   |
| 73  | **OOT workflow** OPEN → ASSESSING (impact notes, affected products/lots; gauge in-charge or quality head) → DISPOSITIONED (quality head only, `oot.decide`, with reason) → CLOSED (optional CAPA ref). Disposition effects on a held instrument: scrap → SCRAPPED; adjusted/repaired/downgraded/use-as-is → IN_STORE (repair is followed by a fresh calibration through the normal flow).                                                                                                                                                                                                | —                                                                   |
| 74  | **AI certificate extraction** (`AI_CERT_EXTRACTION`, model from `AI_MODEL`): the PDF is sent as a document block with a strict zod JSON schema; output only prefills the form, fields under 0.8 confidence are highlighted, a serial-number mismatch is flagged, and nothing is ever auto-approved. The raw output is stored on the job (`aiExtraction`, `aiConfidence`); the human verifier is recorded on the decision. The model call runs outside any DB transaction. If the model refuses or errors, the form stays manual — that's the fallback, so no second model is configured. | Turn the flag off to hide the button.                               |
| 75  | **Readings are stored per point** (`CalibrationReading`) with computed error and pass flags, so the audit pack (M7) and OOT pages show the evidence without re-parsing certificates.                                                                                                                                                                                                                                                                                                                                                                                                     | —                                                                   |
| 76  | **Local file links follow the request's origin** (`/api/attachments/{id}` redirects to `/api/files/…` on the host the user is on), so dev servers on another port than `APP_URL` still open files.                                                                                                                                                                                                                                                                                                                                                                                       | —                                                                   |
